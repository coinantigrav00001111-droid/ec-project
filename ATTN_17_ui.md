## 17.0. Концепт и границы

Сейчас UI вырос из трёх копий «панель категорий + панель объектов» (Build, Operate, Observe) и одной InfoPanel на 779 строк. Нужно привести его к архитектуре, в которую можно добавлять верхнюю панель со статистикой, меню, окно настроек, боковую панель, отладочную панель и перетаскиваемые окна, не копируя код в четвёртый раз.

**Порядок работы (решено):** сначала рефакторинг без изменения внешнего вида, потом новые элементы.

| Фаза | Что делаем | Шаги |
|---|---|---|
| A. Рефакторинг | дефекты, настройки, развязка с игрой, один каталог кнопок, InfoPanel по вкладкам, хоткеи, локализация | U0–U7 |
| B. Каркас и новое | HUD-слоты, TopBar со статистикой, меню, окно настроек, боковая панель, перетаскиваемая InfoPanel, DebugPanel, повтор последнего, DC в Operate | U8–U16 |
| C. Внешний вид | токены темы, иконки, анимации, тултипы и тексты | U17–U20 |
| D. После | масштаб интерфейса, F1-справка, Library, 3D-контроллер | roadmap |

**Вне объёма:** масштабирование интерфейса, полная справка по клавишам (F1), пауза, снимок, индикатор сохранения, часы, содержимое Library, 3D-версия DC-контроллера. Под них оставляем место в раскладке (§17.4), но не строим.

**Целевое разрешение:** HD. Нужно уточнить, что именно: 1280×720 или 1920×1080 (§17.11, вопрос 2). Сейчас окно проекта 1600×900, режим растяжения не задан.

### 17.1.4. Что в архитектуре уже хорошо (не ломаем)

- Правило проекта «сигналы вверх, вызовы вниз» (см. заголовок `ui_generator.gd`) верное, нужно только провести его через границу UI и игры.
- `Hints` как автолоад с контекстами, а не текстами в источниках: образец для остальных сервисов.
- Данные карточек Observe одной константой, ресурсы `EntitySetting` для объектов: каталог уже data-driven.
- Динамические вкладки InfoPanel по компонентам (Mechanisms, Terrain), построенные кодом.
- Один файл темы `theme_gray.tres` и `theme_type_variation` (`ModeButton`, `ObjectButton`, `TagButton`, `HeaderSmall`).

## 17.3. Целевая архитектура

### 17.3.1. Дерево

```
UI (CanvasLayer, layer 0)
├── Services (Node)
│   ├── ModeController          режим, владелец Global.current_mode, реестр режимов
│   ├── ToolbarController       один на все режимы: категории → теги → кнопки
│   └── UIPointer               «курсор над UI?», стек Esc
├── HUD (Control, полный экран, mouse_filter = IGNORE)
│   ├── TopBar                  PanelContainer, на всю ширину, высота 40
│   │   ├── Left:   SystemMenuButton, LayoutNameLabel
│   │   ├── Center: StatsBar (StatChip × N, расширяется)
│   │   └── Right:  ModePanel
│   ├── ToolDock                левый нижний угол: CategoryBar, ActionsStrip, TagColumn, ItemGrid
│   ├── SideDock                выдвижная боковая панель (QoL), справа
│   ├── Floating (Control)      FloatingPanel: InfoPanel, DCPanelHost, DebugPanel
│   └── HintSlot                место под подсказки (сам Hints остаётся автолоадом)
```

Статистику макета (`LayoutStats`) считает игровая модель в `core/layout_stats.gd`, а не UI. Так нет цикла «UI сканирует дерево».

### 17.3.3. Каталог кнопок

Одна механика вместо трёх копий.

```gdscript
class_name CatalogProvider extends RefCounted
signal changed
func get_categories() -> Array[Dictionary]      # {id, title_key, icon}
func get_tags(cat: StringName) -> Array[Dictionary]   # пусто: тегов нет (Observe)
func get_items(cat: StringName, tag: StringName) -> Array[Dictionary]
# item: {id, title_key, icon, tip_key?, group?, toggle?, locked?, payload}
```

| Режим | Провайдер | Кто принимает нажатие |
|---|---|---|
| Build | `EntityCatalogProvider` (ресурсы `EntitySetting`) | `ToolController._on_build_selected` |
| Operate | `EntityCatalogProvider` + `DCCatalogProvider` | `DCPanelHost` или `ToolController` (для 3D) |
| Observe | `CardCatalogProvider` (константа `CARDS`) | `ObserveController.observe_action` |
| Library | `LibraryProvider` (пока пустой, показывает «скоро») | — |

`ToolbarController` один, состояние (последняя категория, тег) хранит по режимам. `CatalogButton` одна сцена, вид задаётся `theme_type_variation` (`ModeButton`, `TagButton`, `ObjectButton`, `Card`). Режим меняет только провайдера и приёмника. Новая категория добавляется в провайдере, без правки сцены и контроллера.

### 17.3.4. Базовые виджеты

| Виджет | Назначение | Где нужен |
|---|---|---|
| `FloatingPanel` | заголовок, перетаскивание, сворачивание, изменение размера, запоминание положения, прижим к экрану | InfoPanel, DC, DebugPanel |
| `SlidePanel` | панель от края экрана, язычок, анимация, закрепление | SideDock |
| `StatChip` | иконка, значение, тултип, скрытие нуля | TopBar |
| `ModalWindow` | затемнение, заголовок, Esc закрывает | Settings, диалоги |
| `ToggleRow`, `SpinRow`, `OptionRow` | строка настройки: подпись + элемент + сброс | Settings, SideDock, DebugPanel |
| `Toast` | короткое сообщение, исчезает само | отказы строительства, сохранение |

### 17.3.5. Правила

- Сигналы вверх, вызовы вниз. Игровой код не получает ссылок на UI, UI подписывается на сигналы игры.
- Узлы находятся через `@export var x: Node` или группы, не строкой `'%' + name`.
- Ни одного абсолютного `offset_*` у HUD-элементов: только якоря, контейнеры и `custom_minimum_size`.
- Каждая панель: `mouse_filter = STOP` на самой панели и `IGNORE` на прозрачных обёртках. Инструменты работают через `_unhandled_input`, поэтому клик по панели до них не доходит. Hover-луч дополнительно спрашивает `UIPointer.is_over_ui()`.
- Любая строка для игрока идёт через `tr(key)`. Строки для отладки не переводятся (помечаются `# no-loc`).
- Размеры, цвета, отступы из темы, не из скриптов (§17.6).

## 17.5. Локализация

### 17.5.1. Требования

- Языки на старте: ru и en. Остальные добавляются колонкой в CSV без правок кода. Fallback: en.
- Смена языка на лету из окна настроек, без перезапуска.
- В коде и сценах нет текстов для игрока, только ключи.
- Макет переживает удлинение текста на 30–40% (русский и немецкий длиннее английского): нет абсолютных ширин под текст, у длинных подписей `autowrap` или `text_overrun_behavior`.
- Данные сохранений не зависят от языка: в сейве id и пути ресурсов, не названия.

### 17.5.2. Архитектура

| Что | Как |
|---|---|
| Хранилище | `locales/ui.csv` (UI, меню, подсказки, настройки, карточки), `locales/content.csv` (названия и описания объектов). Столбцы: `keys,en,ru` |
| Ключи | латиница, `область.раздел.элемент`: `ui.mode.build`, `hint.build.place`, `obj.track_straight_a.name`, `stats.tracks` |
| Код | `tr("ui.mode.build")`; подстановка через `tr("stats.length") % value`; множественное число `tr_n`; контекст вторым аргументом, если одно слово значит разное |
| Сцены | `Label.text` с ключом переводится автоматически (`auto_translate_mode`). Для текста, собранного кодом, ключ хранится, перевод берётся в момент показа |
| Смена языка | `Settings.ui.language` → `TranslationServer.set_locale`. Динамические элементы (Hints, подписи вкладок, карточки) слушают `NOTIFICATION_TRANSLATION_CHANGED` и перестраиваются. Переведённые строки в переменных не кэшируются |
| Первый запуск | язык ОС, если это ru или en, иначе en |
| Шрифт | `Play` покрывает латиницу и кириллицу. Под другие письменности позже добавляется fallback-шрифт в `FontVariation` |
| Контент | `EntitySetting` получает необязательное поле `name_key` и `desc_key`. Если ключа нет, показывается старое `name`, поэтому переход идёт по одному объекту |
| Единицы | подписи единиц (`u/sm`) тоже ключи. Формат десятичных знаков по локали: на потом |

### 17.5.3. Процесс

- **Псевдолокализация.** В настройках проекта Godot есть режим псевдолокализации: удлиняет и «акцентует» все переведённые строки. Включаем на время проверки: непереведённые строки видны сразу, переполнение макета видно сразу.
- **Линтер ключей.** `tests/loc_lint.gd` (EditorScript, запуск из редактора): находит `tr("...")`, которых нет в CSV, и ключи в CSV, не используемые в коде, и строки с кириллицей в `Label.text` сцен.
- **Объём.** По `grep` в `ui/` и `core/` около 210 строковых литералов с кириллицей в `.gd` и около 130 в `.tscn` и `.tres` (`ui/`, `data/`). Часть из них комментарии в кавычках и отладка, реальных строк для игрока примерно 150–250. Переводим только то, что игрок видит в релизе.
- **Правило для новых строк.** В шагах U0–U6 новые тексты остаются русскими и помечаются `# TODO loc`, чтобы U7 их нашёл. С U7 в код попадают только ключи.

### 17.5.4. Что нужно сделать в редакторе один раз

Godot импортирует CSV сам при открытии проекта и создаёт `ui.en.translation` и `ui.ru.translation` (то же для `content`). Их нужно добавить в Project Settings → Localization → Translations. Это единственное действие руками, остальное в патче (проверка в U7).

**Принципы UX, которые стоит держать:**

- Закон Фитса: частое у края (категории внизу слева, режимы вверху справа) и крупное.
- Раскрытие по мере нужды: вкладки InfoPanel показывают только то, что есть у объекта.
- Отклик не медленнее 100 мс: анимации выдвижения 250 мс не блокируют ввод.
- Согласованность: одно слово на одно понятие в обоих языках (Track, Трак, Рельс).
- Состояния: любой элемент имеет normal, hover, pressed, disabled, focus.
